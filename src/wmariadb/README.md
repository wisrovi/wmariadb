# wmariadb Package

Main library package providing MariaDB ORM functionality.

## Key Components

- **core/** - Core database operations (connection, CRUD, table sync)
- **builders/** - Query builder for complex SQL queries
- **exceptions/** - Custom exception classes (WmariadbException, etc.)
- **types/** - Pydantic to MariaDB type mapping
- **cli/** - Command-line interface (wmariadb CLI command)
